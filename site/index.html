Isolation

工作空间与 per-user 隔离

每个活跃用户拥有独立的 Agent ID、工作空间目录和钉钉 binding，停用用户的工作空间会被备份而非删除。

1

Agent 绑定

活跃用户生成 user-{dingtalk_id} 形式的 Agent ID，并通过 bindings 将钉钉私聊 (direct) 路由到对应 Agent。会话范围设为 per-channel-peer。

2

独立工作空间

每个用户的工作空间位于 OpenClaw 容器内 {OPENCLAW_WORKSPACES_PATH}/{dingtalk_id}/，包含 AGENTS.md、SOUL.md、USER.md 等模板文件。

3

allowlist 访问控制

仅活跃用户的 dingtalk_id 写入 channels.dingtalk.allowFrom，配合 dmPolicy: allowlist 限制机器人私聊访问。无活跃用户时使用占位 ID 阻止所有人。

4

备份与恢复

停用用户：工作空间从 workspaces/ 移至 workspaces-backup/。重新启用：从备份目录恢复。新用户：从 workspace-templates/ 初始化文件。

工作空间模板文件

AGENTS.md

Agent 角色和协作机制

BOOTSTRAP.md

系统初始化工作流

监控和告警配置

Agent 身份定义

Sync

同步机制

当用户状态变更时，Admin Panel 自动更新 allowList、同步 Agent binding 并管理工作空间。

✅ 启用用户

  • 创建 Agent + Binding
  • 创建或从备份恢复工作空间
  • 加入钉钉 allowList

⛔ 停用用户

  • 移除 Agent + Binding
  • 备份工作空间至 workspaces-backup
  • 移出钉钉 allowList
1

更新 allowList

修改 OpenClaw 配置中的 channels.dingtalk.allowFrom。

↓
2

同步 Agent

为活跃用户创建 agent binding，移除停用用户的 binding（含 mutex 防并发）。

↓
3

管理工作空间

新用户创建工作空间，停用用户备份，重新启用时恢复。所有操作写入 sync_log 审计表。

Deploy

部署指南

完整管理面板需在具备 Docker 环境的机器上本地部署，默认访问 http://localhost:8088。

前置条件

  • Docker & Docker Compose
  • 运行中的 OpenClaw bot 容器
  • （可选）AnythingLLM 实例
  • 外部 Docker 网络 claworc（docker-compose.yml 中引用）

  1. 克隆项目

    获取源代码到本地。

    git clone https://github.com/UnstoppableCurry/ding-agent-hub.git
cd ding-agent-hub

  2. 配置环境变量

    复制示例配置并修改密码与容器相关设置。

    cp .env.example .env
# 编辑 .env，修改 JWT_SECRET、ADMIN_PASSWORD 和容器配置

  3. 启动服务

    构建并后台运行 admin-panel 容器。

    docker compose up -d --build

  4. 登录管理面板

    访问 http://localhost:8088，使用 .env 中配置的 ADMIN_USERNAME / ADMIN_PASSWORD 登录。

环境变量

环境变量配置表
变量 说明 默认值

DOCKER_SOCKETDocker socket 路径/var/run/docker.sock

OPENCLAW_WORKSPACES_PATHbot 容器内工作空间路径/home/claworc/.openclaw/workspaces
ANYTHINGLLM_URLAnythingLLM 地址http://anythingllm:3001
ANYTHINGLLM_API_KEYAnythingLLM API Key（空）
MONITOR_CONTAINERS监控的容器名（逗号分隔）bot-openclaw-1
ADMIN_PORT宿主机端口映射8088

安全注意事项

  • 务必修改默认的 JWT_SECRET 和 ADMIN_PASSWORD
  • Docker socket 挂载赋予了容器对宿主机 Docker 的完全访问权限
  • 建议在内网环境部署，或配置反向代理 + HTTPS

Notes

说明与限制

以下为本项目的实际约束，本静态文档站不包含任何虚构的功能承诺或演示数据。

!

无在线演示：管理面板依赖 Fastify 后端、SQLite 数据库、Docker Socket 及 OpenClaw 容器，无法在 GitHub Pages 上运行交互式 Demo。

!

依赖外部 OpenClaw：需预先部署并运行 OpenClaw bot 容器，且 admin-panel 须接入 claworc Docker 网络。

!

AnythingLLM 为可选组件：部门级知识库功能需单独部署 AnythingLLM 并配置 API Key。

!

Docker Socket 权限：容器挂载宿主机 Docker socket，具有对 Docker 守护进程的完全访问权限，部署时需谨慎评估。

!

默认凭据需修改：开箱即用的 admin/admin123 和默认 JWT 密钥仅适用于开发测试。

!

无截图/演示素材：本页面未包含管理面板截图；UI 基于 Ant Design 组件库构建，具体界面请以本地部署为准。
